================================================================================
RUN_LOSSES DIRECTORY PURPOSE
================================================================================

The run_losses/ subdirectories contain simple 2-panel plots:
  1. Validation Accuracy over epochs
  2. Validation Loss over epochs

Purpose: Quick check to see if training completed and converged
  - If curves are still changing → need more epochs
  - If curves are flat → training converged

================================================================================
VANISH_GRAD.PY DETAILS
================================================================================

Special features:
  • Tests different starting positions in the permutation
  • starting_position=0 means perm[0] is source
  • starting_position=1 means perm[1] is source
  • starting_position=2 means perm[2] is source
  
  • Labels in plots: "Starting Position 1, 2, 3" (offset by +1)
  
  • 10K validation samples (10x more than other experiments)
  
  • Pickle contains full training history for all runs:
    all_results[starting_pos] = {
        'train_history': [...],
        'val_history': [...],
        'starting_pos': starting_pos
    }
